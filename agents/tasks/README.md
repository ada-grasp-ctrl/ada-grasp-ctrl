# Historical task records

The Markdown files in this directory are maintained historical audit records. They are not agent instructions and
must not be loaded as normative project context. Current behavior is defined by `README.md`, `agents/rules/`, code,
configuration, and tests.

Keep existing records for traceability even when they describe superseded behavior. New transient agent or editor
state belongs in the ignored `.agents/` or `.codex/` directories; add a new file here only when it is intentionally
reviewed and maintained as repository documentation.
