# DGN 2k quick-example subset

The bundled object and scene files are a selected subset of the original DGN 2k collection distributed with the
[BODex dataset](https://huggingface.co/datasets/JiayiChenPKU/BODex).

The subset contains the 89 processed objects and 100 scene configurations referenced by the maintained three-hand
quick inputs. The selected DGN files are copied without content changes. Exact paths, sizes, SHA-256 values, counts,
and aggregate digests are recorded in [`examples/quick_manifest.json`](../../../quick_manifest.json).
